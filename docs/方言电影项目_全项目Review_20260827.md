## 四、前端构建检查：check:contracts 断言失败

`npm run check` 在 contracts 阶段报错：

```
index.html flop case IDs mismatch: 26796665, 22557335, 6068516, 3874981, 6068516
```

原因：未提交的 index.html 新增了"同导演对照"的 `director-film` 按钮（`data-movie-id="6068516"` 等），与烂片案例共用 movieId 6068516，导致 `check-contracts.mjs` 的 `extractFlopCaseIds` 提取出 5 个 ID（期望 4 个唯一值）。

修复方向（三选一，推荐 1）：
1. 收紧 `extractFlopCaseIds` 的匹配（如限定 `data-lang="flop"` 或独立 class）；
2. 调整 HTML 标记让两类案例可区分；
3. 若 director 对照属于新场景体系，同步更新 FLOP_CASE_IDS 契约语义。

注意：**此问题提交前必须修**，否则 CI 的 `npm run check` 一挂，push 就红。
